## About

Modular Express Starter is a feature-based Node.js backend boilerplate designed to save time and provide a clean project structure.

It demonstrates how to organize modules, controllers, services, and routes for scalable development.

TypeScript, Prisma, PostgreSQL, and Docker setup will be added soon.

This starter helps developers focus on coding without worrying about architecture.

## Features (Coming Soon)

- Modular, feature-based architecture

- Prisma ORM integration
